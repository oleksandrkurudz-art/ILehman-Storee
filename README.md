# ILehman-Store

Навчальний проєкт інтернет-магазину техніки Apple на React. Каталог, сторінки товарів, кошик та обране з українським інтерфейсом.

Проєкт у розробці. Товари, ціни й характеристики — демонстраційні дані. Оформлення замовлення працює локально: перевіряє поля, показує тестове підтвердження та очищає кошик. Дані не надсилаються на сервер, оплата не підключена.

## Можливості

- Пошук товарів за назвою.
- Сторінка товару з описом, ціною та схожими товарами.
- Додавання в кошик, зміна кількості, видалення й підрахунок суми.
- Додавання та видалення обраних товарів.
- Збереження кошика й обраного в `localStorage` поточного браузера.
- Форма контактних даних покупця з базовою перевіркою полів.
- Сторінки «Про нас», «Контакти» та сторінка для невідомої адреси.
- Адаптивні стилі для різних розмірів екрана; мобільна версія ще допрацьовується.

## Технології

React 19, React Router 7, Vite 8, JavaScript, SCSS та Oxlint. Спільний стан кошика й обраного реалізований через React Context.

## Локальний запуск

Потрібні Node.js, сумісний із Vite 8, та npm. Для розробки можна використовувати Node.js 22.12+ у гілці 22.

```bash
npm ci
npm run dev
```

Відкрий адресу, яку Vite покаже в терміналі.

## Команди

```bash
npm run dev      # запуск сервера розробки
npm run build    # збірка в dist
npm run preview  # локальний перегляд готової збірки
npm run lint     # перевірка коду
```

## Структура

```text
public/          зображення товарів і favicon
src/
  assets/        зображення для інтерфейсу
  components/    компоненти, контексти кошика й обраного
  data/          демонстраційний каталог
  pages/         сторінки та їхні стилі
  styles/        загальні стилі й SCSS-змінні
  utils/         форматування ціни
  App.jsx        маршрути та спільна розмітка
  main.jsx       точка входу
```

## Що планується

- Розширити каталог і додати фільтри та сортування.
- Додати характеристики, фото та вибір комплектації товарів.
- Завершити перевірку мобільної версії.
- Додати доставку та збереження замовлень на сервері.
- Перевіряти ціни й наявність перед оформленням замовлення.
- Реалізувати відгуки та заповнити інформаційні сторінки.

## Розміщення сайту

Для публікації використовується папка `dist`, створена командою `npm run build`. Через `BrowserRouter` хостинг має повертати `index.html` для адрес сторінок, наприклад `/cart` і `/product/2`.
